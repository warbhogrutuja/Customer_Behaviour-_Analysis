# Customer Behaviour Analysis

A data analytics project focused on understanding customer purchasing behaviour, subscription patterns, product category performance, and sales trends using SQL, Python, and Power BI.

## Project Overview

The objective of this project is to analyze customer shopping data and identify patterns that can help businesses better understand their customers and evaluate sales performance.

The project follows an end-to-end analytics workflow, from data exploration and SQL querying to interactive dashboard development.

## Dataset

- **Dataset:** Customer Shopping Behaviour
- **Records:** 3,900
- **Features:** 18
- **Format:** CSV

The dataset includes customer information, purchase details, product categories, subscription status, shipping preferences, and review ratings.

## Tools & Technologies

- **SQL:** PostgreSQL
- **Python:** Pandas, NumPy, Jupyter Notebook
- **Visualization:** Power BI
- **Dataset:** CSV

## Project Workflow

### 1. Data Exploration & Preparation
- Loaded and explored the customer shopping dataset using Python.
- Examined dataset structure, data types, and missing values.
- Performed data preparation for further analysis.

### 2. SQL Analysis
- Used SQL queries to explore customer purchasing behaviour.
- Analyzed customer and product-related information.
- Examined sales patterns across different categories and customer groups.

### 3. Power BI Dashboard

Developed an interactive Customer Behavior Dashboard featuring:

- **Key Performance Indicators:** Average Purchase Amount, Average Review Rating, and Number of Customers.
- **Subscription Analysis:** Customer distribution by subscription status.
- **Category Analysis:** Sales and revenue by product category.
- **Age Group Analysis:** Sales and revenue comparisons across age groups.
- **Interactive Filters:** Subscription status, gender, category, and shipping type.
